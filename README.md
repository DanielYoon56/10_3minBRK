# Korea3MinTrader — 3분봉 시가돌파 자동매매 (내 PC 전용)

키움증권 REST API로 국내주식을 자동매매하는 Windows 데스크톱 앱입니다.

| 구분 | 규칙 |
|---|---|
| 감시종목 | 매일 장 전 자동 선정: **키움 조건식 결과 AND 전일 매집**(① 거래량 급증·양봉·고가 근처 마감 **또는** ② 외국인·기관 순매수 상위) |
| 18시 스캔 | 평일 **18:00** 장 마감 후 매집 확인 스캔 → 결과 창 표시 + **텔레그램 전송** → 다음 날 감시종목으로 사용 |
| 매수 | 3분봉 종가가 **첫 3분봉 시가**를 상향 돌파 + 돌파 봉 거래량 > 첫 봉 거래량의 **70%** |
| 매도 | ① 손절 **-2%** ② 트레일링: **+1% 이상** 오른 뒤 상승분의 **15%** 되돌림 ③ **15:15 일괄 청산** |
| 안전 | 앱이 산 종목만 매도 · 지나간 신호 무시 · 일 손실한도 · 중복 실행/주문 방지 |
| 알림 | 텔레그램: 매수·체결·손절·트레일링·일괄청산·오류·일일 요약·**18시 매집 종목** |
| 자동 실행 | 평일 08:50 PC 깨움 → 앱 실행 → 자동매매 시작 → 15:40 자동 종료 · 평일 18:00 매집 스캔 |

## 1. 설치 (최초 1회)

1. [python.org](https://www.python.org/downloads/)에서 **Python 3.11 이상** 설치
   - 설치 첫 화면에서 **"Add python.exe to PATH" 체크** 필수
2. 이 폴더를 원하는 위치에 둡니다 (예: `C:\Korea3minTrader`)
   - 폴더 경로에 한글·공백이 없으면 가장 안전합니다
3. **`setup.bat`** 더블클릭 → "설치 완료"가 나오면 끝

## 2. 실행

- **`run.bat`** 더블클릭
- 문제가 있을 때는 `run_console.bat`(검은 창에 로그 표시)으로 실행해 오류 내용을 확인

---

## 3. 키움증권 연결

1. 키움증권 계좌 → [키움 OpenAPI 포털](https://openapi.kiwoom.com)에서 REST API 사용 신청
2. **모의투자용 / 실거래용 앱키**를 각각 발급 (서로 바꿔 쓰면 접속 안 됨)
3. 포털에 **이 PC의 공인 IP** 등록 (공유기 IP가 바뀌면 다시 등록)
4. 모의거래를 쓰려면 키움 **상시 모의투자** 신청
5. 앱 **[키움 API 설정]** 탭 → 키 입력 → **저장** → **연결 테스트**

### 모의거래 / 실거래 전환
- 우측 상단 **[모의거래] [실거래]** 버튼
- 실거래 전환 시 `실거래` 를 직접 입력해야 바뀜, 시작할 때 금액·한도 요약을 한 번 더 확인
- 파란 배너 = 모의거래, **빨간 배너 = 실제 돈**

## 4. 감시종목 자동 선정 (키움 조건식 + 전일 매집)

```
키움 조건식 결과 (주가 1,000원↑ · 시총 3,000억↑ 등 쌤의 필터)
        ↓ AND
전일 매집:  ① 거래량 ≥ 20일 평균 2배 + 양봉 + 고가 근처 마감(윗꼬리 25% 이하) + 거래대금 30억↑
        또는 ② 외국인 또는 기관 순매수 상위 20위 (10억↑)
        ↓
그날 감시종목 (최대 30개) → 3분봉 시가돌파 매수
```

### 조건식 준비 (영웅문 HTS)
1. 영웅문 **[0150] 조건검색** → 조건식 작성 (예: 주가 ≥ 1,000원, 시가총액 ≥ 3,000억, 관리종목 제외 …)
2. **"서버 저장"** — 저장해야 앱에서 보입니다
3. 앱 **[전략 설정]** → **[조건식 목록 불러오기]** → 조건식 선택
4. **[지금 스캔]** 으로 오늘 선정될 종목 미리보기

### 동작
- 자동매매를 켜 두면 **08:00 이후 1회 자동 스캔** (스캔 중에도 손절·트레일링 감시는 계속)
- 결과는 휴대폰으로 알림 + `python_app/screen_날짜.json` 저장 (당일 재시작 시 재사용)
- **조건식 조회가 실패하면 그날은 신규 매수를 하지 않습니다** (조건 없이 사지 않도록)
- 조건식을 비워 두면 전 시장(전일 거래량·거래대금 상위 200)에서 매집 종목을 고르고, 이때만 앱의 주가·시총 필터 적용
- 매집 기준 수치는 [전략 설정]에서 조정 가능
- `python_app/logs/condition_raw_날짜.json` — 키움 조건검색 응답 원본 (형식 확인용, 문제 시 보내주세요)

### 18시 매집 확인 스캔 + 텔레그램 (장 마감 후)

```
평일 18:00  작업 스케줄러가 evening_scan.bat 실행 (앱이 꺼져 있어도 동작)
        ↓
오늘 확정 일봉 기준 매집 스캔 (후보: 오늘 거래량·거래대금 상위 200, 기준 수치는 [전략 설정] 그대로)
        ↓
① 콘솔 창에 결과 종목 표시 (Enter 로 닫기)
② 텔레그램으로 같은 내용 전송
③ screen_다음평일.json 저장 → 다음 날 아침 앱이 다시 스캔하지 않고 그대로 감시종목으로 사용
```

- **등록 (1회)**: `evening_scan_install.bat` 더블클릭 → 작업 스케줄러 `Korea3minTrader_EveningScan` 등록
- **해제**: `evening_scan_uninstall.bat`
- **지금 바로 실행**: `evening_scan.bat`
  - 15:40 이전과 주말에는 건너뜀 (오늘 일봉이 아직 확정 전이라서)
  - 강제 실행: `evening_scan.bat --force` · 텔레그램 없이 보기만: `evening_scan.bat --no-telegram`
- PC가 18시에 꺼져 있었다면 켜진 뒤 실행 (단, 다음 날 15:40 이전이면 건너뜀)
- 조건식을 설정한 경우 조건식 결과 AND 매집으로 고름 (아침 스캔과 같은 규칙)

텔레그램 수신 예:
```
📋 18시 매집 스캔 [모의거래] 기준일 2026-10-21
→ 2026-10-22 감시종목 30개 (후보 91) [①거래량·캔들 2 / ②수급 28]
1. 명신산업(009900) ①
   거래량 12.6배·양봉·고가대비 24% 아래 마감·대금 786억 · 10,060원 · 시총 5,278억
2. 삼성전자(005930) ②외국인+②기관
   외국인 순매수 7,724억 · 기관 순매수 706억 · 223,500원 · 시총 13,066,433억
…
```
종목이 많아 4,000자를 넘으면 여러 메시지로 나눠 보냅니다.

## 5. 텔레그램 알림 설정 (5분)

1. 휴대폰 텔레그램에서 **@BotFather** 검색 → `/newbot` → 봇 이름 입력
2. BotFather가 준 **토큰**(`123456789:ABC...`)을 복사
3. 방금 만든 봇을 열고 **아무 메시지**(예: `안녕`) 전송
4. 앱 **[알림·자동실행]** 탭 → 봇 토큰 붙여넣기 → **[chat_id 자동 찾기]** → **[테스트 메시지]**
5. 휴대폰에 메시지가 오면 **저장**

받게 되는 알림 예:
```
[실거래] 📈 매수 주문 삼성전자 98주 (시장가, 신호가 71,200원)
[실거래] ✅ 매수 체결 삼성전자 98주 @ 71,300원 (손절 69,874원)
[실거래] 📉 매도 주문 삼성전자 98주 — 트레일링 스탑: 최고가 73,500 대비 …
[실거래] 🟢 매도 체결 삼성전자 98주 ≈73,170원 → 추정손익 +170,000원
[실거래] 📊 당일 마감 요약 …
📋 18시 매집 스캔 [실거래] 기준일 … → 다음 날 감시종목 N개 …
```
- 봇 토큰 칸에는 **토큰 하나만** 넣으세요. 두 개를 이어 붙이면 `텔레그램 전송 실패 [404]: Not Found` 가 납니다.
같은 오류는 5분에 한 번만 보내므로 알림이 쏟아지지 않습니다.

## 6. 평일 자동 실행 설정

1. 앱 **[알림·자동실행]** 탭에서 옵션 확인
   - ✅ 자동 실행으로 켜지면 자동매매까지 자동 시작
   - ☐ **실거래 모드도 자동 시작 허용** — 켜려면 `실거래` 입력 필요. 꺼져 있으면 실거래 모드일 때 시작하지 않고 휴대폰으로 알림
   - ✅ 장 종료 후(15:40) 자동매매 중지 + 앱 종료
2. **[Windows 자동 시작 등록]** 버튼 (또는 `autostart_install.bat` 더블클릭)
3. 해제: **[등록 해제]** 버튼 (또는 `autostart_uninstall.bat`)

동작:
- 평일 **08:50** 작업 스케줄러가 앱을 실행 (창은 최소화 상태)
- PC가 **절전 중이면 깨워서** 실행 (아래 전원 설정 필요)
- PC가 꺼져 있었다면 **켜진 뒤** 실행 — 이미 지나간 신호로는 매수 안 함
- 키움 접속 실패 시 1분 간격 5회 재시도 (절전 해제 직후 인터넷 지연 대비)
- 앱이 이미 켜져 있으면 두 번째 실행은 자동 취소 (중복 주문 방지)
- 18시 매집 스캔은 별도 작업(`Korea3minTrader_EveningScan`)입니다 — [4장 18시 매집 확인 스캔](#18시-매집-확인-스캔--텔레그램-장-마감-후) 참고

### Windows 전원 설정 (꼭 확인)
| 설정 | 위치 | 값 |
|---|---|---|
| 절전 모드 | 설정 → 시스템 → 전원 → 화면 및 절전 | 장중엔 **안 함** 권장 |
| 절전 해제 타이머 | Win+R → `control powercfg.cpl` → 사용 중인 구성표의 "설정 변경" → "고급 전원 관리 옵션 설정 변경" → 절전 → 절전 모드 해제 타이머 허용 (Windows 설정 앱엔 없음) | **사용** ("중요 절전 모드 해제 타이머만"이면 안 깨어남) |
| 업데이트 재부팅 | 설정 → Windows 업데이트 → 사용 시간 | **08:00~16:00** 포함 |
| 로그인 | — | 로그아웃하지 말고 **화면 잠금**만 사용 (로그아웃 상태에선 실행 안 됨) |

## 7. ⚠ 꼭 알아둘 점

- **감시·매도는 이 앱이 켜져 있을 때만 작동**합니다. PC가 꺼지거나 인터넷이 끊기면 손절도 안 됩니다.
  - 보조 안전망: 영웅문 HTS **[0624] 자동감시주문**에 매수 종목 **손실제한 -2.5%** 등록 (키움 서버가 감시, PC 꺼져도 작동)
- 앱을 껐다 켜도 최고가(트레일링 기준)는 이어서 사용합니다.
- 15:15 전에 앱이 꺼져 청산 못 한 종목은 **다음 날 09:00에 시장가 청산**됩니다 (설정에서 끌 수 있음).
- 계좌에 원래 있던 종목은 **절대 건드리지 않습니다.**
- 손익은 수수료·세금을 반영한 **추정치**입니다. 정확한 금액은 키움 HTS/MTS에서 확인하세요.
- 공휴일에도 앱은 실행되지만 시세가 없어 주문은 나가지 않습니다.

### 실거래 전 권장 순서
1. **모의거래로 1~2주** 자동 실행 운영 → 텔레그램 알림과 `logs` 폴더 로그 확인
2. 실거래 첫 주는 **1회 매수금액 10~30만원**, 일 손실한도도 작게
3. 체결 품질(시장가 슬리피지) 확인 후 금액 상향

## 9. 문제 해결

| 증상 | 확인 |
|---|---|
| 연결 테스트 실패 | 모의/실거래 키를 맞는 칸에 넣었는지, 키움 포털 IP 등록, 모의투자 신청 여부 |

| 로그에 `텔레그램 전송 실패 [404]` | 봇 토큰이 틀렸거나 토큰 두 개가 붙어 있음 → 토큰 하나만 다시 입력 |

| 18시 스캔 창이 안 뜸 | 작업 스케줄러에 `Korea3minTrader_EveningScan` 있는지, 로그아웃 상태 아닌지 · 수동으로 `evening_scan.bat` 실행해 오류 확인 |
